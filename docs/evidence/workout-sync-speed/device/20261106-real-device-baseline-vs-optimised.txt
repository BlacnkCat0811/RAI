# Real device baseline vs optimised — same device, same Workout, same build

The build carries two internal rollback switches (`AcceptanceSwitches`, DEBUG-only, environment driven):
`RAI_ACCEPTANCE_LEGACY_CAPTURE_IO=1` restores one record (and one route/series point) per flush instead of
the 512-record / 256 KiB / 250 ms policy, and `RAI_ACCEPTANCE_LEGACY_ENCODER=1` restores the previous
`JSONEncoder` writer. Both produce byte-identical bundles (`bundle_bytes` 8,565,743 in every sample of both
states), so the two states upload the same bytes and differ only in client cost.

P1 (source gate) and P3 (discovery reuse) cannot change a first import of an already eligible Workout, so
this pair isolates exactly the P2 and P3-encoder work for `T_user_ack`.

## Baseline (both rollback switches on), n=5

- `workout_sync_ms`: P50 25103.2 / P95 25359.2 / min 24386.5 / max 25359.2 (n=5)
- `healthkit_read_ms`: P50 15993.5 / P95 16362.9 / min 15616.1 / max 16362.9 (n=5)
- `bundle_build_ms`: P50 19184.4 / P95 19616.1 / min 18687.8 / max 19616.1 (n=5)
- `upload_ms`: P50 5620.4 / P95 6091.5 / min 5597.5 / max 6091.5 (n=5)
- `bundle_encode_ms`: P50 2532.6 / P95 2632.4 / min 2475.2 / max 2632.4 (n=5)

## Optimised (shipped path), n=20

- `workout_sync_ms`: P50 19144.8 / P95 19652.6 / min 18371.0 / max 19760.7 (n=20)
- `healthkit_read_ms`: P50 12783.1 / P95 12967.2 / min 12054.7 / max 13378.2 (n=20)
- `bundle_build_ms`: P50 13532.5 / P95 13735.4 / min 12797.6 / max 14189.1 (n=20)
- `upload_ms`: P50 5609.9 / P95 5872.9 / min 5282.7 / max 5893.4 (n=20)
- `bundle_encode_ms`: P50 136.6 / P95 149.6 / min 130.4 / max 155.2 (n=20)

## Result

- Baseline P50 **25103.18 ms**, optimised P50 **19144.76 ms** → **-23.7%**
- Absolute saving 5958 ms, of which the encoder accounts for ~5652 ms and per-point capture I/O the rest.
- The plan's P01 clause asks for at least a 50% drop against P0 on the same terms: **that clause FAILS at -23.7%**.
  The remaining 19.1 s is dominated by per-sample `NSKeyedArchiver` (8.8 s) and server import (~5 s), neither of
  which the P0–P6 plan authorised changing.
